Guide d'installation

Dans l'app Raccourcis. Les fichiers vont dans iCloud Drive › Raccourcis.

01 · Focus Ouvrir

  1. Obtenir le fichier deep.txt, « Erreur si introuvable » désactivé.
  2. Obtenir les dates de l'entrée.
  3. Si Dates est après Date actuelle → Afficher la notification « Deep en cours » → Arrêter ce raccourci. Fin si.
  4. Obtenir les nombres de l'entrée : Entrée du raccourci.
  5. Ajuster la date : ajouter Nombres minutes à Date actuelle.
  6. Texte : Date ajustée, format ISO 8601.
  7. Enregistrer le fichier acces.txt, « Demander où » désactivé, « Remplacer » activé.
  8. Afficher la notification « Accès ouvert ».

02 · Focus Deep

  1. Obtenir le fichier deep.txt (sans erreur) → Obtenir les dates de l'entrée.
  2. Si Dates est après Date actuelle → notification « Deep déjà en cours » → Arrêter ce raccourci. Fin si.
  3. Obtenir les nombres de l'entrée : Entrée du raccourci.
  4. Ajuster la date : ajouter Nombres heures à Date actuelle.
  5. Texte : Date ajustée (ISO 8601) → Enregistrer le fichier deep.txt (remplacer).
  6. Afficher la notification « Deep lancé ».

03 · Focus Garde

  1. Obtenir le fichier deep.txt (sans erreur) → Obtenir les dates de l'entrée.
  2. Si Dates est après Date actuelle → Ouvrir les URL https://mayner33.github.io/Focus-/?fin= suivi de Fichier → Arrêter ce raccourci. Fin si.
  3. Obtenir le fichier acces.txt (sans erreur) → Obtenir les dates de l'entrée.
  4. Si Dates est après Date actuelle → rien. Sinon → Ouvrir les URL https://mayner33.github.io/Focus-/. Fin si.

04 · Automatisation

  1. Automatisation › App › TikTok, Instagram…
  2. « Est ouverte », Exécuter immédiatement, sans notification.
  3. Action : Exécuter le raccourci Focus Garde.

« Focus Ouvrir » lancé à la main n'ouvre rien : il ne reçoit aucune durée.
